## 详细问题分析

### 问题 #1: load_entry malloc 未检查 NULL

```c
// template_filler.c:31
uint8_t* data = malloc(st.size);
*len = zip_fread(f, data, st.size);  // data 可能 NULL!
zip_fclose(f);
return data;
```

**建议修改**:
```c
uint8_t* data = malloc(st.size);
if (data == NULL) {
    zip_fclose(f);
    return NULL;
}
*len = zip_fread(f, data, st.size);
zip_fclose(f);
return data;
```

### 问题 #4: fill_index malloc 未检查 NULL

```c
// template_filler.c:327-328
result->sst_indices = malloc(row_count * col_count * sizeof(int));
result->xf_indices = malloc(row_count * col_count * sizeof(int));
// 未检查 NULL，后续 write 操作会崩溃
```

**建议修改**:
```c
result->sst_indices = malloc(row_count * col_count * sizeof(int));
if (result->sst_indices == NULL) return CXLSB_ERR_NO_MEMORY;
result->xf_indices = malloc(row_count * col_count * sizeof(int));
if (result->xf_indices == NULL) {
    free(result->sst_indices);
    result->sst_indices = NULL;
    return CXLSB_ERR_NO_MEMORY;
}
```

### 问题 #5: generate_filled_sheet 固定缓冲区

```c
// template_filler.c:398
uint8_t* sheet = malloc(65536);  // 固定 64KB
```

对于大 sheet（如 1000+ 行），可能超出边界。

**建议**: 动态计算所需大小：
```c
size_t estimated_size = 1024 + (max_row - start_row + 1) * (128 + max_col * 20);
uint8_t* sheet = malloc(estimated_size);
```
